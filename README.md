# Broadcast Pro · User Mode

Telegram-панель для управляемых рассылок в группы и каналы от имени подключённого пользовательского аккаунта.

## Как устроено

- BotFather-бот используется только как админ-панель.
- Отправка выполняется пользовательским аккаунтом через Telegram MTProto / Telethon.
- Контент кампании берётся из `Избранного` подключённого аккаунта.
- Целевые группы/каналы добавляются вручную по `@username` или `-100...` ID.
- Есть несколько администраторов и роли owner/admin/editor/viewer.
- Есть теги чатов, шаблоны, статистика, health-check, пауза/продолжение и остановка кампаний.
- Интервалы: 15 мин, 30 мин, 1 час, 2 часа или своё число минут (минимум 15).
- Можно запустить одиночную рассылку сразу или на конкретную дату/время.
- FloodWait Telegram соблюдается автоматически.

Используйте автоматизацию только в группах/каналах, где такие сообщения разрешены.

## Railway variables

```env
BOT_TOKEN=
OWNER_IDS=123456789
API_ID=
API_HASH=
USER_SESSION=
DATABASE_URL=${{Postgres.DATABASE_URL}}
TIMEZONE=Asia/Yekaterinburg
SEND_DELAY_SECONDS=1.1
WORKER_POLL_SECONDS=5
MAX_RECIPIENTS_PER_CAMPAIGN=500
MAX_RETRIES=2
LOG_LEVEL=INFO
```

`USER_SESSION`, `API_HASH` и `BOT_TOKEN` — секреты. Не публикуйте их и не отправляйте другим людям.

## 1. Получить API_ID / API_HASH

Откройте `https://my.telegram.org` → `API development tools` → создайте приложение. Сохраните `api_id` и `api_hash`.

## 2. Один раз создать USER_SESSION локально

На Windows в папке проекта:

```powershell
py -m venv .venv
.venv\Scripts\python.exe -m pip install "Telethon>=1.45,<2"
.venv\Scripts\python.exe generate_session.py
```

Скрипт попросит `API_ID`, `API_HASH`, номер телефона, код Telegram и при необходимости пароль 2FA. Всё вводится локально в терминале.

В конце появится длинная строка `USER_SESSION`. Добавьте её в Railway Variables и затем удалите/закройте вывод терминала, если компьютер общий.

## 3. Использование

1. Убедитесь, что аккаунт-отправитель состоит в нужной группе/канале и имеет право писать.
2. В админ-панели: `💬 Чаты` → `➕ Добавить чат` → отправьте `@username` или ID.
3. Положите рекламный пост или альбом в `Избранное` аккаунта-отправителя.
4. В панели: `📣 Новая рассылка` → название → аудитория.
5. Выберите интервал `15 мин / 30 мин / 1 час / 2 часа` или свой.
6. Перед запуском нажмите `🧪 Тест в Избранное`.
7. Создайте кампанию. Её можно поставить на паузу, продолжить или остановить.

## Безопасность

Не вводите Telegram-код входа или пароль 2FA в управляющего бота. Для авторизации используется только локальный `generate_session.py`. Никому не передавайте `USER_SESSION`: она даёт доступ к Telegram-сессии подключённого аккаунта.
