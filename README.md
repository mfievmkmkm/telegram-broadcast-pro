# Telegram Broadcast Pro

Продвинутая админ-панель для рассылок по Telegram-группам и каналам, в которые бот уже добавлен и где ему разрешено публиковать сообщения.

## Что умеет

- несколько владельцев и администраторов;
- роли `owner`, `admin`, `editor`, `viewer`;
- подключение групп и каналов;
- проверка прав бота в каждом чате;
- включение/выключение получателей без удаления;
- теги аудиторий (`football`, `partners`, `chelyabinsk` и т.п.);
- отправка во все чаты или только по выбранному тегу;
- контент-пакеты до 100 исходных сообщений;
- текст, фото, видео, документы, голосовые и другие копируемые типы Telegram;
- копирование альбомов/пакетов через `copyMessages`;
- CTA URL-кнопка под постом;
- тестовая отправка самому администратору перед запуском;
- отправка сейчас, через 10 минут или в конкретную дату/время;
- циклические кампании по интервалу;
- пауза активной кампании и продолжение с оставшихся получателей без дублей;
- полная остановка;
- повторный запуск завершённой кампании;
- обработка Telegram FloodWait;
- повторные попытки при временных ошибках;
- настраиваемая задержка между чатами;
- лимит получателей на кампанию;
- статистика доставок и последних запусков;
- аудит основных действий;
- health-check прав в чатах;
- шаблоны сообщений;
- SQLite локально или PostgreSQL в продакшене;
- состояние кампаний сохраняется в базе и переживает перезапуск сервиса.

## Роли

| Роль | Возможности |
|---|---|
| `owner` | всё + управление админами |
| `admin` | чаты, кампании, шаблоны, статистика |
| `editor` | создание кампаний и шаблонов |
| `viewer` | просмотр панели и статистики |

Владельцы задаются переменной `OWNER_IDS`. Можно указать несколько ID через запятую.

## Быстрый запуск

1. Создай Telegram-бота через BotFather.
2. Скопируй `.env.example` в `.env`.
3. Заполни минимум:

```env
BOT_TOKEN=123456:ABC...
OWNER_IDS=111111111,222222222
```

4. Установи зависимости:

```bash
pip install -r requirements.txt
```

5. Запусти:

```bash
python run.py
```

## Добавление чата

### Группа

Добавь бота в группу и отправь в группе:

```text
/register_here
```

Команду должен отправить пользователь с ролью `admin` или `owner` в Broadcast Pro.

### Канал

1. Добавь бота администратором канала.
2. Разреши публикацию сообщений.
3. В панели открой `💬 Чаты` → `➕ Добавить чат`.
4. Пришли `chat_id` вида `-100...` или публичный `@username`.

## Кампания

`📣 Новая рассылка` → название → одно или несколько сообщений → `Готово` → аудитория → расписание → при необходимости CTA → `Тест себе` → `Создать кампанию`.

## Переменные

```env
BOT_TOKEN=
OWNER_IDS=123456789
DATABASE_URL=sqlite+aiosqlite:///data/bot.db
TIMEZONE=Asia/Yekaterinburg
SEND_DELAY_SECONDS=1.1
WORKER_POLL_SECONDS=5
MAX_RECIPIENTS_PER_CAMPAIGN=500
MAX_RETRIES=2
LOG_LEVEL=INFO
```

### PostgreSQL

Для Railway рекомендуется PostgreSQL. Подойдёт обычный URL:

```env
DATABASE_URL=postgresql://user:password@host:5432/dbname
```

Код автоматически переключит его на asyncpg-драйвер.

## Важное ограничение

Бот предназначен для управляемых вами групп/каналов. Он не ищет случайные чаты и не обходит ограничения Telegram: получатель должен быть зарегистрирован в панели, а бот должен иметь право писать туда.
